DEBATE METHODOLOGY

This system uses research-backed techniques to produce objective, bias-resistant analysis.

MULTI-AGENT ADVERSARIAL DEBATE

Two AI agents argue opposing sides while an independent evaluator scores and a fact-checker verifies claims via web search.

Du et al. (ICML 2024) — multi-agent debate improves factuality. Anthropic (2024) — debate → 76% judge accuracy vs 54% without.

INDEPENDENT FACT-CHECKING

A separate agent verifies factual claims via web search, rating each VERIFIED / LIKELY TRUE / UNVERIFIED / DISPUTED / FALSE.

Citation-blind: sources verified on content, not authority (arXiv:2512.09483). Up to 10 research queries per round.

EVALUATOR DEBIASING (5 corrections)

• Anti-position bias — arguments evaluated independently of presentation order (arXiv:2406.07791)

• Anti-verbosity bias — quality ≠ length; concise evidence beats padding (arXiv:2310.10076)

• Anti-confidence bias — bold assertions don't count as evidence (arXiv:2505.02151)

• Anti-rhetoric bias — logical content scored separately from emotional appeal (arXiv:2504.00374)

• Anti-anchoring — each round scored independently, no momentum bias (arXiv:2309.17012)

Chain-of-thought evaluation: evaluator reasons through each criterion before scoring (Wharton Tech Report 2025).

Anti-sycophancy: scores of 2-8 or 8-2 expected when one side dominates; 5-5 requires explicit justification (arXiv:2509.23055).

AGENT SELF-VERIFICATION

Both debaters verify their own claims before submitting. Numbers double-checked, citations confirmed.

Anticipatory reflection catches hidden assumptions (arXiv:2405.16334). Socratic sub-questioning for complex claims (arXiv:2303.08769).

CALIBRATED VERDICTS

7-tier scale: CONFIRMED → STRONGLY SUPPORTED → LIKELY TRUE → INCONCLUSIVE → LIKELY FALSE → STRONGLY REFUTED → REFUTED.

Confidence percentage extracted separately. Future predictions cannot be CONFIRMED/REFUTED — only the evidenced range applies.

WEB-GROUNDED RESEARCH

All agents can search the web for real-time evidence. Research results are attributed and visible in the Research pane.

SUMMARIZER DEBIASING

Anti-recency: all rounds weighted equally. Anti-verbosity: argument length ≠ argument quality. Substance over rhetoric.

Recency bias documented in all 7 tested LLMs (arXiv:2509.11353).
